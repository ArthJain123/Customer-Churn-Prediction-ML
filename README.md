# Customer Churn Prediction ML

🚧 **Work in Progress**

A machine learning project focused on analyzing customer churn and building models to predict whether a customer is likely to leave.

## 📌 Project Overview

Customer churn refers to customers who stop using a company's products or services.

The goal of this project is to:

* Understand customer behavior
* Explore factors related to churn
* Perform data cleaning and preprocessing
* Analyze the dataset using visualization
* Build machine learning classification models
* Evaluate and compare model performance

## 🛠️ Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab

## 🤖 Machine Learning Models
